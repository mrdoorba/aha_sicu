## Goal
Add code coverage enforcement, CI PostgreSQL service, shared test fixtures, email endpoint integration tests, and clean up redundant async markers.

## Purpose
Fill test coverage gaps identified by AEGIS audit (F-06-001, F-06-002, F-06-004, F-06-005, F-06-006, F-10-008, F-00-007). Without coverage measurement, regressions ship undetected. Without CI database service, integration tests are untestable. Without email endpoint tests, the email feature's full request-response cycle is unvalidated.

- `backend/tests/conftest.py` with shared auth fixtures

- Redundant `@pytest.mark.asyncio` decorators removed from 17 test files
