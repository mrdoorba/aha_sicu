<acceptance_criteria>

## AC-1: WIF Branch Restriction
```gherkin
Given a WIF provider for the dev environment
When the attribute_mapping is inspected
Then it includes "attribute.ref" mapped to "assertion.ref"
And the attribute_condition requires both the correct repository AND "refs/heads/develop"

Given a WIF provider for the prod environment
When the attribute_mapping is inspected
Then the attribute_condition requires "refs/heads/main"
```

## AC-2: Cloud SQL Authorized Networks Lockdown
```gherkin
Given the Cloud SQL instance ip_configuration
When no authorized_networks variable is provided
Then zero authorized_networks entries are generated (empty default = no public IP access)

Given the authorized_networks variable is set to a non-empty list
When terraform plan is run
Then the specified networks appear in the ip_configuration
```

## AC-3: Evaluation Schema Literal Types
```gherkin
Given an evaluation response schema with a status field (e.g., SingleCalculatorStatus)
When a value outside the allowed set is provided
Then Pydantic raises a validation error

Given response schemas like EvaluationListItem, ScoringResponse
When the template or verdict field is inspected
Then it uses CategoryType or VerdictType (Literal) instead of bare str
```

<task type="auto">
  <name>Task 2: Lock down Cloud SQL authorized_networks</name>
  <files>infrastructure/terraform/cloud_sql.tf, infrastructure/terraform/variables.tf</files>
  <action>
    1. In root `variables.tf`, add:
       ```
       variable "authorized_networks" {
         description = "List of authorized networks for Cloud SQL public IP access. Empty = no public access."
         type = list(object({
           name  = string
           value = string
         }))
         default = []
       }
       ```

    2. In `cloud_sql.tf`, add a `dynamic "authorized_networks"` block inside the existing `ip_configuration`:
       ```
       dynamic "authorized_networks" {
         for_each = var.authorized_networks
         content {
           name  = authorized_networks.value.name
           value = authorized_networks.value.value
         }
       }
       ```

    Avoid: Removing `ipv4_enabled = true` — the Cloud SQL Proxy sidecar still needs it.
    Avoid: Adding a `private_network` reference — this project doesn't use VPC peering.
  </action>
  <verify>cd infrastructure/terraform && terraform fmt -check -recursive . && terraform validate <!-- audit-added: machine-verifiable TF checks --></verify>
