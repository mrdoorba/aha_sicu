## Challenges & Growth Areas

1. **Async/blocking gotchas** - Firebase SDK `verify_id_token` is synchronous; required `asyncio.to_thread` wrapper
2. **Framework migration surprises** - Tailwind CSS v4 uses different plugin and import syntax than v3
3. **Accessibility as afterthought** - Modal focus trapping, aria attributes caught in review, not designed upfront
4. **File tracking gaps** - Files claimed in story records that didn't actually exist
5. **Limited visibility during development** - Struggles surfaced at code review, not during development

---

## Key Insights

1. **Pattern discovery is front-loaded** - Epic 2 should be faster now that patterns are established
2. **Need better real-time visibility** - Surface blockers and discoveries as they happen
3. **Accessibility should be a checklist item** - Not a review finding
4. **Google Sheets API will likely have similar async challenges** - Be proactive with research
