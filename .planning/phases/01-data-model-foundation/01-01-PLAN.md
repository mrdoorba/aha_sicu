Create `backend/app/db/migrations/versions/026_add_marketplace_to_schema.py` with:

- `revision = "026"` and `down_revision = "025"`
- `upgrade()` function that does (in order):

**1. scoring_rules table:**
```sql
ALTER TABLE scoring_rules
    ADD COLUMN marketplace VARCHAR(2) NOT NULL DEFAULT 'ID'
        CHECK (marketplace IN ('ID', 'TH'));
```

Then drop old UNIQUE and add new compound UNIQUE:
```sql
ALTER TABLE scoring_rules
    DROP CONSTRAINT IF EXISTS scoring_rules_template_key,
    ADD CONSTRAINT uq_scoring_rules_template_marketplace
        UNIQUE (template, marketplace);
```

Then read the existing `default/ID` row using `conn = op.get_bind()` and `sa.text()`:
```python
row = conn.execute(
    sa.text("SELECT rules, version FROM scoring_rules WHERE template = 'default' AND marketplace = 'ID'")
).fetchone()
```

Parse rules JSONB, convert ONLY `business.six_month_avg_threshold.threshold` by multiplying with `0.0019` (result: `190000.0`). All other thresholds stay identical. Insert the THB row:
```python
conn.execute(
    sa.text(
        "INSERT INTO scoring_rules (template, marketplace, rules, version, updated_at) "
        "VALUES ('default', 'TH', CAST(:rules AS jsonb), :version, NOW())"
    ),
    {"rules": json.dumps(rules), "version": row[1]},
)
```

**2. evaluation_inputs table:**
```sql
ALTER TABLE evaluation_inputs
    ADD COLUMN marketplace VARCHAR(2) NOT NULL DEFAULT 'ID'
        CHECK (marketplace IN ('ID', 'TH'));
```

**3. evaluations table:**
```sql
ALTER TABLE evaluations
    ADD COLUMN marketplace VARCHAR(2) NOT NULL DEFAULT 'ID'
        CHECK (marketplace IN ('ID', 'TH'));
```

- `downgrade()` function that reverses: drop marketplace columns from all three tables, restore old UNIQUE constraint on scoring_rules, delete the THB rules row.

Import `json`, `sqlalchemy as sa`, and `from alembic import op`.
