**DashboardHeader.tsx modifications:**

1. Add `onSendEmail?: () => void` to `DashboardHeaderProps` interface (optional for backwards compat)
2. Import `Mail` from `lucide-react` (add to existing import)
3. Add a Send Email button BEFORE the Edit Evaluation button (left of it per user decision). The button:
   - `variant="outline"` (per user decision)
   - `className="rounded-xl h-10 px-5 font-bold"` (matching Edit button height h-10)
   - `onClick={onSendEmail}` -- calls the callback
   - Contents: `<Mail className="mr-2 size-4" />` + `{t('sendEmail.sendButton')}` ("Kirim Email")
   - Only render if `onSendEmail` is provided (conditional rendering for backward compat)

4. Wrap the two action buttons (Send + Edit) in a `div className="flex items-center gap-3"` to keep them grouped.

**PresentationDashboard.tsx modifications:**

1. Import `useRef, useState` from React
2. Import `SendEmailDialog` from `./SendEmailDialog`
3. Add `const chartRef = useRef<HTMLDivElement>(null)` for chart capture target
4. Add `const [sendDialogOpen, setSendDialogOpen] = useState(false)` for dialog state
5. Cast `evaluation.brand_raw_data` to `BrandRawData` type (import from `../../hooks/useEvaluationDetail`)

6. Pass `chartRef` to ScoreBreakdownChart:
   ```tsx
   <ScoreBreakdownChart ref={chartRef} scoreBreakdown={scoreBreakdown} />
   ```

7. Pass `onSendEmail` callback to DashboardHeader:
   ```tsx
   <DashboardHeader
     brandName={brand?.brand_name || evaluation.brand_name}
     brandId={brandId}
     verdict={evaluation.verdict}
     template={evaluation.template}
     period={evaluation.period}
     onBack={onBack}
     onSendEmail={() => setSendDialogOpen(true)}
   />
   ```

8. Add SendEmailDialog at the end of the return JSX (inside the outer div, after DashboardFooter):
   ```tsx
   <SendEmailDialog
     open={sendDialogOpen}
     onOpenChange={setSendDialogOpen}
     evaluationId={evaluation.id}
     brandName={brand?.brand_name || evaluation.brand_name}
     period={evaluation.period}
     score={Math.round(evaluation.final_score)}
     brandRawData={evaluation.brand_raw_data as BrandRawData}
     chartRef={chartRef}
   />
   ```

Note: The `evaluation` object from `useEvaluationDetail` already has `brand_raw_data` typed as `BrandRawData` via the `EvaluationDetail` interface, so the cast may not be needed -- check if TypeScript is happy without it. If the intermediate `data as EvaluationDetail` cast in the hook already covers it, no additional cast needed.
