  <action>
    Create backend/app/modules/email/service.py with:

    1. Helper function `_load_asset(filename: str) -> bytes` — reads image from `Path(__file__).parent / "assets" / filename`.

    2. Function `_strip_base64_prefix(data: str) -> str` — strips "data:image/png;base64," or similar data URI prefix if present.

    3. Function `_decode_chart_image(chart_image_b64: str) -> bytes` — strips prefix, decodes base64, raises AppException(code="INVALID_CHART_IMAGE", status_code=422) on failure.

    4. Function `build_email_message(*, subject, from_name, from_email, to_email, html_content, text_content, images: list[tuple[bytes, str, str]])` returning EmailMessage:
       - Uses email.message.EmailMessage
       - Sets Subject, From (f"{from_name} <{from_email}>"), To headers
       - set_content(text_content) for plain text fallback
       - add_alternative(html_content, subtype="html") for HTML
       - For each image tuple (data, subtype, cid): html_part.add_related(data, "image", subtype, cid=cid)

    5. Function `_smtp_send_sync(msg: EmailMessage) -> str` — synchronous SMTP send:
       - smtplib.SMTP(settings.smtp_host, settings.smtp_port, timeout=30)
       - server.starttls(), server.login(settings.smtp_user, settings.smtp_password), server.send_message(msg)
       - Returns Message-ID
       - Catches SMTPAuthenticationError -> AppException(code="SMTP_AUTH_ERROR", status_code=502)
       - Catches SMTPConnectError -> AppException(code="SMTP_CONNECTION_ERROR", status_code=502)
       - Catches TimeoutError -> AppException(code="SMTP_TIMEOUT", status_code=504)

    6. Async function `smtp_send(msg: EmailMessage) -> str` — wraps _smtp_send_sync in asyncio.to_thread().

    7. Async function `send_evaluation_email(*, evaluation_data: dict, recipient: str, chart_image_b64: str, subject: str | None = None, render_html_fn: Callable) -> SendEmailResponse`:
       - Generate subject if not provided: f"Laporan Evaluasi Brand: {brand_name} - {period}"
       - Decode chart image via _decode_chart_image
       - Load header/footer assets via _load_asset
       - Generate CIDs via make_msgid(domain="ahacommerce.id") for each image, strip angle brackets for HTML references
       - Call render_html_fn(evaluation_data=evaluation_data, chart_cid=chart_cid, header_cid=header_cid, footer_cid=footer_cid) to get HTML
       - Generate plain text fallback (simple summary: brand name, score, verdict)
       - If not settings.email_enabled: write HTML to /tmp/email_preview_{evaluation_id}.html, return SendEmailResponse(success=True, message_id="debug-file", recipient=recipient)
       - Otherwise: build_email_message() and smtp_send(), return SendEmailResponse with actual message_id
       - Log failures only (not successes) per decision

    Create backend/tests/unit/email/test_service.py with tests for all behaviors above. Use conftest fixtures. Mock smtplib.SMTP for SMTP tests. Mock settings for email_enabled toggle.
